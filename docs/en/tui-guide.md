# TUI Guide

Launch with `artcraft` or `artcraft tui`.

Keys:

- `q` / `Esc` — quit.
- `↑` / `↓` — navigate.
- `Space` — select / deselect an app.
- `Enter` — open application details.
- `a` — apply selected apps (confirm modal).
- `e` — execute in confirm modal.
- `c` / `Esc` — cancel modal.
- `p` — change preferred installation method.
- `i` / `u` / `r` — install / upgrade / remove in details modal.
