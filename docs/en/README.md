# artcraft-tui

`artcraft` is a production-quality CLI/TUI for discovering, installing, diagnosing,
updating, repairing, and reconciling installations of the ArtCraft creative application suite.

## Features

- Comprehensive installation discovery across package managers and portable formats.
- User-defined preferred installation methods.
- Detection of mixed, duplicate, inconsistent, and broken installations.
- Declarative reconciliation toward a desired installation state.
- Preservation of user-created data during migrations.
- Auditable, resumable, and recoverable operations.
- A polished, colorful, keyboard-first TUI.
- A powerful noninteractive CLI for scripts and automation.
